# AIView Workflow Studio

AIView multi-agent workflow studio MVP. It guides a task through topic selection, a mind map, a six-field plan, artifact creation, and a final retrospective.

## Requirements

- Node.js 18 or newer
- npm

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The app can run in offline mode with deterministic fallbacks, or connect to an OpenAI-compatible API from the settings panel.

## Verify

```bash
npm test
npm run build
```
